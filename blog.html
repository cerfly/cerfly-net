How I Built This Site — No Frameworks, No Excuses

September 2026 · Web Development

When I decided to build a personal website, I could have used any template or framework. Instead, I chose to type every line of HTML, CSS, and JavaScript myself. Why? Because I wanted to understand what I was shipping. If I don't know how something works, I can't fix it when it breaks — and I'm a strong believer in fixing my own messes.

This site started as four pages and a stylesheet. It grew a dark/light theme, a skills section, and now lives on Cloudflare Pages. Every deploy is a git push. That's it. Simple, boring, and completely mine.
