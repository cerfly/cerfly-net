Qué hago ahora

Última actualización: septiembre de 2026

💻 Construyendo cerfly.net

Construyendo este mismo sitio junto a opencode con HTML, CSS y JS puro. Sin frameworks, sin complicaciones.

🤖 Aprendiendo

Profundizando en JavaScript y explorando cómo hacer la web más accesible.

📖 Leyendo

Four Thousand Weeks — Oliver Burkeman. Suena a libro de productividad, pero es lo contrario: Burkeman parte de que la vida humana son unas 4.000 semanas, que ningún sistema acabará con tu bandeja de entrada, y que la verdadera habilidad es aceptar qué cosas dejarás pasar. Me ha servido más que cualquier truco de gestión del tiempo.

How to Simplify Your Life — Tiki Kustenmacher y Lothar J. Seiwert. Más que una filosofía, es una lista: siete ámbitos (cosas, dinero, tiempo, salud, relaciones, pareja y tú mismo) con gestos concretos para soltar lastre. Hay partes que se notan antiguas, pero la pregunta «¿esto tiene que ser tan complicado?» se me ha quedado.

🛠 Herramientas del oficio

Viviendo en Linux Mint con VS Code, git para el control de versiones, opencode como compañero de código con IA y software libre para todo lo demás.

🏠 Mi stack favorito

HTML/CSS/JS puros para este sitio, Python para scripts y automatizaciones rápidas.
